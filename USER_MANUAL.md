## Getting Started

### What is Kaching?

Kaching is a mobile app that helps you:
- **Track** where your money goes
- **Budget** your monthly spending
- **Save** toward your goals
- **Get insights** into your spending habits

### System Requirements

| Requirement | Details |
|-------------|---------|
| **iOS** | iPhone/iPad with iOS 13 or newer |
| **Android** | Android devices 8.0 or newer |
| **Internet** | Required for registration; |
| **Storage** | ~50MB free space |

### Download & Install

1. Download Expo Go app from App Store or Google Play
2. Scan QR code from `npm start` output
3. App opens in Expo Go
4. Ready to use!

## First Time Setup

### Step 1: Create Your Account

**Duration:** 2 minutes

1. **Open Kaching app**
2. **Click "Create Account"**
3. **Enter your details:**
   - Email: your@email.com
   - Password: Create a strong password (min 6 characters)
   - Confirm Password: Re-enter password
4. **Click "Sign Up"**

5. **Complete Profile:**
   - Navigate to "Profile"
   - Enter your name
   - Upload profile picture (optional)
   - Confirm your name
   - Set Phone Number
   - Click "Save Changes"

### Step 2: Set Your Monthly Budget

**Duration:** 1 minute

1. **Go to Home screen**
2. **Find "Current Monthly Budget"**
3. **Enter amount** (e.g., 15000 for ₱15,000)
4. **Budget is saved automatically**

### Step 3: Add First Expense

**Duration:** 2 minutes

1. **Click "+ Add Expense" button**
2. **Enter expense details:**
   - Description: What you bought
   - Amount: How much (₱)
   - Category: Type of expense
   - Date: When it happened
3. **Click "Save"**
4. **Expense added to list**

## Step-by-Step Tutorials

### Tutorial 1: Adding Your First Expense

**Goal:** Learn how to record an expense

**Time:** 3 minutes

1. **On Home screen, click "+ Add Expense" button**
   - Or navigate to "Add Expense" from menu

2. **In the form, fill:**
   - **Description field:** "Lunch at restaurant"
   - **Amount field:** "350" (for ₱350)
   - **Category dropdown:** Select "Food"
   - **Date picker:** Choose today's date

3. **Click "Submit" button**
   - App confirms: "Expense added successfully"

4. **View your expense:**
   - Go to "Expense List"
   - See your new expense at top of list

✅ **You've successfully added an expense!**

---

### Tutorial 2: Setting a Monthly Budget

**Goal:** Set how much you can spend monthly

**Time:** 2 minutes

1. **Go to Home screen**

2. **Find "Current Monthly Budget" section**

3. **See "Change Budget" button**
   - Click it

4. **Enter your budget:**
   - For example: "25000" (₱25,000/month)
   - Use realistic number based on your income

5. **Click "Save Budget"**
   - Confirmation message appears

6. **Budget now active:**
   - App tracks spending against this limit
   - You'll see "₱X remaining" in budget display

✅ **Your monthly budget is set!**

---

### Tutorial 3: Creating a Savings Goal

**Goal:** Save money toward a specific target

1. **Go to Savings screen** (from bottom menu)

2. **See "Savings Goal" section**

4. **Click "Save Goal" button**

5. **Add to savings:**

6. **Track progress:**

✅ **Your savings goal is active!**

## Tips & Best Practices

**From the app's built-in tips:**

1. **Save 20% of Income**
   - If you earn ₱50,000, save ₱10,000
   - Set savings goal for this amount

2. **Track Daily**
   - Add expenses every day

   - More accurate tracking

   - Protects your savings

4. **Budget = Conscious Spending**
   - Set realistic monthly budget
   - Monitor remaining amount
   - Adjust mid-month if needed

5. **Emergency Fund is Essential**
   - Create savings goal: "Emergency Fund"
   - Target 3-6 months expenses
   - Use Kaching to track progress

6. **Automate Savings**
   - Set recurring savings transfer
   - Use Kaching reminder for deposit day
   - Stay consistent

7. **Cook at Home**
   - Reduce food category spending
   - Track meals vs. eating out
   - See monthly savings

8. **Cut Unused Subscriptions**
   - Review expense categories
   - Cancel unused services
   - Redirect to savings goal

9. **Regular Budget Reviews**
   - Check spending weekly
   - Adjust categories as needed
   - Plan for next month

10. **Emergency Fund Goal**
    - Save ₱15,000 - ₱50,000
    - Start with whatever possible
    - Build gradually

## FAQ

### Q: Is Kaching free?
**A:** Yes! Kaching is completely free to use. No hidden fees or premium plans.

### Q: Is my data secure?
**A:** Yes. Your data is encrypted and stored securely with Supabase. Passwords are hashed. Personal data never shared.

### Q: Can I use Kaching offline?
**A:** Yes! App works fully offline. Data syncs to cloud when you reconnect.

### Q: What happens if I lose my phone?
**A:** Your data is safe. Login on new device with your email/password to recover all data.

### Q: Can I export my expenses?
**A:** Yes. Go to Settings → Export Data to download expenses as CSV/PDF file.

### Q: How many expenses can I track?
**A:** Unlimited. Kaching handles thousands of expenses smoothly.

### Q: Can I have multiple accounts?
**A:** Yes, you can create different accounts for different email addresses.

### Q: How far back can I view expenses?
**A:** All expense history is preserved. View any transaction ever recorded.

### Q: Can I change my budget mid-month?
**A:** Yes. Anytime in Home screen, update budget amount. Changes take effect immediately.

### Q: Can I delete my account?
**A:** Yes. Go to Settings → Account → Delete Account. This removes all your data.

### Q: Does Kaching have a web version?
**A:** Yes! Run `npm start` then press `w` for web version.

### Q: What currencies does Kaching support?
**A:** Currently shows in Philippine Peso (₱). Multi-currency support coming soon.

### Q: Can I share expenses with someone?
**A:** Not yet. Shared budgeting features planned for future.

### Q: Why am I not seeing my savings goal?
**A:** Make sure goal name and amount are filled in. Click "Save Goal" to confirm.

### Q: How do I reset my password?
**A:** On login screen, click "Forgot Password?" and follow email instructions.

### Q: Can I use Kaching on tablet?
**A:** Yes. App is responsive and works on tablets.

## Troubleshooting

### Problem: Can't Login

**Error Message:** "Invalid email or password"

**Solutions:**
1. ✓ Double-check email spelling
2. ✓ Verify caps lock is off
3. ✓ Try password reset: "Forgot Password?"
4. ✓ Check internet connection
5. ✓ Update Kaching to latest version
6. ✓ Clear app cache and retry

**Steps to clear cache:**
- Android: Settings → Apps → Kaching → Storage → Clear Cache
- iOS: Settings → General → iPhone Storage → Kaching → Offload App

---

### Problem: Expenses Not Saving

**Error Message:** "Failed to save expense" or expense disappears

**Solutions:**
1. ✓ Check internet connection
2. ✓ Verify all fields are filled:
   - Description (required)
   - Amount (required, must be number)
   - Category (required)
   - Date (required)
3. ✓ Verify amount is valid number (no letters)
4. ✓ Try again after 10 seconds
5. ✓ Close app and reopen
6. ✓ Check device storage isn't full

---

### Problem: Budget Not Updating

**Budget amount doesn't change when you click save**

**Solutions:**
1. ✓ Check internet connection
2. ✓ Verify budget amount is valid number
3. ✓ Refresh home screen (pull down)
4. ✓ Close and reopen app
5. ✓ Go to Home → try setting budget again

---

### Problem: Savings Goal Not Appearing

**Goal doesn't show after clicking "Save Goal"**

**Solutions:**
1. ✓ Check you entered goal name (required)
2. ✓ Check you entered goal amount (required)
3. ✓ Verify amount is greater than 0
4. ✓ Verify amount is valid number
5. ✓ Refresh savings screen
6. ✓ Try creating goal again

---

### Problem: Data Not Syncing

**Changes not appearing on other device or data lost**

**Solutions:**
1. ✓ Check internet connection
2. ✓ Try manual backup: Home → Menu → Backup Now
3. ✓ Close and reopen app (triggers auto-sync)
4. ✓ Wait 1 minute for sync to complete
5. ✓ Log out and log back in
6. ✓ Check Supabase status online

---

### Problem: Profile Picture Not Uploading

**Image doesn't save when uploading profile picture**

**Solutions:**
1. ✓ Check internet connection
2. ✓ Verify image file size < 5MB
3. ✓ Try different image
4. ✓ Grant camera/gallery permissions:
   - Android: Settings → Apps → Kaching → Permissions
   - iOS: Settings → Kaching → Photos
5. ✓ Try JPEG format instead of PNG
6. ✓ Close app completely and reopen

---

### Problem: App Crashes

**App freezes or closes suddenly**

**Solutions:**
1. ✓ Close app completely (swipe up)
2. ✓ Wait 10 seconds
3. ✓ Reopen app
4. ✓ Clear app cache (see login troubleshooting)
5. ✓ Uninstall and reinstall Expo Go
6. ✓ Restart phone
7. ✓ Update Kaching to latest version

---

### Problem: Slow Performance

**App is sluggish or slow to load**

**Solutions:**
1. ✓ Close other apps running in background
2. ✓ Clear app cache
3. ✓ Restart phone
4. ✓ Check internet connection speed
5. ✓ Delete oldest expenses (keep recent year)
6. ✓ Reduce number of photos on device

---

### Problem: Notification Not Working

**You're not getting notifications for budget alerts**

**Solutions:**
1. ✓ Go to Settings → enable notifications
2. ✓ Check phone settings:
   - Android: Settings → Apps → Kaching → Notifications → ON
   - iOS: Settings → Notifications → Kaching → Allow
3. ✓ Restart phone
4. ✓ Update app to latest version

---

### Problem: Stuck on Splash Screen

**App shows splash screen but doesn't load main app**

**Solutions:**
1. ✓ Wait 30 seconds (first load is slow)
2. ✓ Check internet connection
3. ✓ Go to Expo Go app and try again
4. ✓ Restart Expo Go app
5. ✓ Run `npm start` again and scan QR code
6. ✓ Restart phone
